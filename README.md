# dotfiles

My personal dotfiles. Feel free to copy specific configs, but I don't recommend cloning the entire repository.

This setup uses [Stow][stow] for installation.

## Installation

```bash
# Clone dotfiles repo to your home directory
git clone https://github.com/vkhalash/dotfiles.git $HOME/.dotfiles

# Go to the dotfiles directory
cd $HOME/.dotfiles

# Install dotfiles
./install.sh
```

[stow]: https://github.com/aspiers/stow
